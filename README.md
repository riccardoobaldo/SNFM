# SN4M (Social Network For Music)

Progetto per il corso di Applicazioni Web e Cloud (A.A. 2024/2025).

## Descrizione
Applicazione web interamente client-side per la ricerca, gestione e condivisione di playlist musicali e creazione di community.

## Tecnologie utilizzate
- HTML, CSS, JavaScript (Vanilla)
- Spotify Web API per la ricerca dei brani
- LocalStorage per la persistenza dei dati
